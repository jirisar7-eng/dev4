## 1. Cíl a rozsah úkolu
Implementace a ověření reusable lifecycle orchestration engine (`ModuleLifecycleEngine`) v `@tmpr/module-engine/lifecycle` s využitím existujícího `ModuleRegistry`. Zajištění deterministického řízení stavů modulů (uninstalled -> install -> installed -> enable -> enabled -> disable -> disabled -> enable -> enabled -> uninstall -> uninstalled).

### Klíčové architektonické požadavky:
- Zamezení neplatných stavových přechodů (fail-closed s chybou `INVALID_TRANSITION`).
- Zajištění chování hook failure, kdy se nesmí vytvořit falešný úspěšný stav.
- Validace, že se správně udržuje route index a manifest dat během (od)registrace.
- Podpora pro dependency resolution (blokace při neuspokojených závislostech).
- Těsná integrace se stávající architekturou (registry, contract, scaffolding).
