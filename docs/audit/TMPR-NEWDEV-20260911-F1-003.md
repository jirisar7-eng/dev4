## 1. Cíl a rozsah úkolu

Vytvoření autoritativního, projektově neutrálního běhového registru modulů (`ModuleRegistry`) v balíčku `@tmpr/module-engine` jako součásti vrstvy Synthesis OS / Platform Services.

Registr modulů:
- Spravuje `moduleKey`, runtime `IModule`, validovaný `manifest`, `version`, `state` (ModuleLifecycleState) a deklarované routy/surfaces.
- Vynucuje fail-closed validaci manifestu a platformní kompatibility (`synthesisCore`, `synthesisCms`).
- Garantuje unikátnost `moduleKey` (jeden klíč právě jednou v registru).
- Indexuje deklarované routy a fail-closed odmítá kolize na stejné kombinaci `surface + path`.
- Poskytuje čisté rozhraní pro evidenci běhového stavu (`recordState`) bez předčasného spouštění lifecycle hooků.
- Je striktně oddělen od Dependency Resolveru a cycle detection (řešeno v samostatném navazujícím tasku).
- Je plně in-memory bez persistence do databáze v této fázi.

## 3. Architektonické a bezpečnostní principy

1. **Platform Neutrality (Synthesis OS)**:
   - Registr neobsahuje žádné doménové entity, názvy projektů (žádné "Táta má právo", "rodinné právo", "CoParentHub").
   - Testy používají výhradně syntetické a platformní identifikátory (`platform.auth`, `test.module-a`, `test.core-compat` apod.).
2. **Fail-Closed Behavior**:
   - Nevalidní manifest → okamžitá chyba `INVALID_MANIFEST`.
   - Nekompatibilní jádro → okamžitá chyba `CORE_VERSION_INCOMPATIBLE`.
   - Deklarované CMS bez runtime CMS verze → okamžitá chyba `CMS_VERSION_REQUIRED`.
   - Nekompatibilní CMS verze → okamžitá chyba `CMS_VERSION_INCOMPATIBLE`.
   - Duplicitní `moduleKey` → okamžitá chyba `DUPLICATE_MODULE_KEY`.
   - Kolize deklarované cesty na stejné surface → okamžitá chyba `ROUTE_CONFLICT`.
3. **Atomicity**:
   - Dojde-li během registrace modulu k jakékoliv chybě (např. konflikt 3. routy v poli), modul ani žádné jeho předchozí routy nejsou do registru zapsány.
4. **Oddělení vrstev a odpovědností**:
   - Module Registry nespouští lifecycle hooky (`onInstall`, `onEnable` atd.).
   - Module Registry neřeší graf závislostí ani cycle detection — modul s chybějící `required` závislostí se v registru úspěšně zaregistruje (test 14).
   - Module Registry nepřipojuje routy do Next.js ani NestJS — pouze spravuje autoritativní vlastnictví deklarovaných rout.
