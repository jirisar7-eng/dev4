## 1. Cíl a rozsah úkolu

Implementace deterministického CLI a programatického generátoru standardního doménového modulu podle aktuálního Module Contractu monorepa DEV4.

### Klíčové architektonické požadavky:
1. **Povinných 9 částí standardního modulu:**
   - `manifest` — autoritativní manifest modulu plně validní vůči Zod schématu `ModuleManifestSchema` a integrovatelný do `ModuleRegistry`.
   - `contract` — veřejný kontrakt vystavený přes subpath export `./contract` v `package.json` pro zamezení úniku interních detailů (`ERR-ARCH-005`).
   - `domain` — čistá doménová logika, typy a entity bez vnějších závislostí.
   - `data` — repozitáře a decentralizované datové vlastnictví.
   - `api` — API handlery a servisní rozhraní.
   - `public` — veřejně přístupné komponenty / fasády.
   - `admin` — administrátorské rozhraní a RBAC definice.
   - `help` — balíček nápovědy a dokumentace (`help/cs/index.md`).
   - `tests` — automatické unit testy spustitelné přímo v rámci modulu (`tests/index.test.ts`, `tsconfig.test.json`).
   - `migrations` / `database` — vlastní databázové schéma `database/schema/schema.prisma` a SQL migrace `database/migrations/0001_initial/migration.sql`.
2. **Bezpečnost a validace vstupů:**
   - Striktní validace `moduleKey` podle jmenného prostoru (`NAMESPACED_MODULE_KEY_REGEX`), zákaz velkých písmen, podtržítek a prázdných hodnot.
   - Validní formát SemVer.
   - Bezpečné odmítnutí existujícího neprázdného cílového adresáře bez explicitního přepínače `--overwrite`.
3. **Deterministický výstup:**
   - Opakované spuštění se shodnými vstupními parametry vytváří identický bajtový obsah.
   - Podpora režimu náhledu (`--dryRun`) a strojového formátu (`--json`).
4. **Brand Neutrality a Boundary Compliance:**
   - Nulový výskyt specifického projektového textu či značek ("tata-ma-pravo", "Táta má právo", "tatovacesta", barvy projektu).
   - Nulový výskyt zakázaných balíčků ("bullmq", "redis", "ioredis").
   - Vygenerovaný modul musí projít kontrolou `pnpm test:boundaries` bez porušení architektonických pravidel (`ERR-ARCH-001` až `ERR-ARCH-008`).
