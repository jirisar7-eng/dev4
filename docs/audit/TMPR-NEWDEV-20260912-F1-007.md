## 2. Architektonické řešení a implementace

Pro kontrolu nebyl použit křehký regex matching, nýbrž robustní TypeScript AST parser, který syntakticky analyzuje veškeré formy importů a exportů.

Vytvořen samostatný balíček `packages/boundary-gate`:
1. `src/ast-parser.ts`:
   - Používá `typescript` Compiler API (`ts.createSourceFile`).
   - Zachycuje:
     - statické importy (`import ... from '...'`)
     - import types (`import type ... from '...'`)
     - re-exporty (`export * from '...'`, `export { ... } from '...'`)
     - dynamické importy (`import('...')`)
     - CommonJS volání (`require('...')`)
   - Extrahuje přesné řádky, sloupce a specifikátory.
2. `src/classifier.ts`:
   - Určuje architektonickou vrstvu pro zdrojové soubory (`synthesis-os`, `synthesis-cms`, `project`, `domain-module`, `app`, `shared`).
   - Normalizuje relativní cesty vůči kořeni monorepa a mapuje je na kanonické balíčky a vrstvy.
   - Detekuje relativní pokusy o obcházení vrstev (např. `../../modules/family-alimony` z balíčku `synthesis-core`).
   - Klasifikuje importy do jiných modulů na `contract` vs. `internal`.
3. `src/rules.ts`:
   - Implementuje formální pravidla `ERR-ARCH-001` až `ERR-ARCH-008`.
   - Každé porušení obsahuje zdrojový soubor, řádek, sloupec, cílový specifikátor, kód pravidla a český popis porušení s doporučeným řešením.
   - Pravidla jsou obecná a nevytvářejí nepatřičný projektový hardcoding.
4. `src/scanner.ts`:
   - Rekurzivně skenuje složky `packages/*`, `modules/*`, `apps/*`.
   - Zajišťuje agregaci výsledků a formátovaný český report.
5. `src/cli.ts`:
   - Spustitelný skript pro CI a lokální běh.
   - Deterministicky lokalizuje kořen monorepa.
   - V případě nálezu porušení ukončuje proces s exit kódem 1.
